# java_learning
# Estudos em Java

Repositório onde guardo os projetos que faço durante meu aprendizado de Java. 
São exercícios simples, criados para praticar e demonstrar a minha evolução

## Projetos

- **Hello_World**: Classico Olá, Mundo!
- **Horasdo_Sistema**: Informa as horas, lingua, país e resolução do seu sistema.
- **Tipos_Primitivos**: Primeiro contato com variantes e objetos. Pega dados meus e informa ao usuário.
- **Testando_printf**: Utilizo do printf para mostrar um número de diversas formas.
- **Entradade_Dados**: Uso da entrada de dados junto do printf para demonstrar número (escolhido pelo usuário) de formas diferentes.
- **Calculadorade_Soma**: lê dois números, soma e pergunta ao usuário se o resultado está correto.
- **Calculadorade_Idade**: Utiliza de LocalData para calcular sua idade baseada no ano atual e no do seu nascimento.
- **Operadores_Aritmetico**: Realiza operações aritméticas com dois números escolhidos pelo usuário.
