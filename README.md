# java_learning

Repositório onde guardo os projetos que faço durante meu aprendizado de Java. 
São exercícios simples, criados para praticar e demonstrar a minha evolução.

## Projetos

- **hello_world**: Clássico Olá, Mundo!
- **horas_do_sistema**: Informa as horas, língua, país e resolução do seu sistema.
- **tipos_primitivos**: Primeiro contato com variáveis e tipos primitivos. Pega dados meus e informa ao usuário.
- **testando_printf**: Utilizo o printf para mostrar um número de diversas formas.
- **entrada_de_dados**: Uso da entrada de dados junto com o printf para demonstrar número (escolhido pelo usuário) de formas diferentes.
- **calculadora_de_soma**: lê dois números, soma e pergunta ao usuário se o resultado está correto.
- **calculadora_de_idade**: Utiliza a classe LocalDate para calcular sua idade baseada no ano atual e no do seu nascimento.
- **operadores_aritmeticos**: Realiza operações aritméticas com dois números escolhidos pelo usuário.
- **operadores_ternarios**: Utilizo if e else para fazer comparações e simplifico o código utilizando operadores ternários.
- **operadores_relacionais_logicos**: Utilizo operadores relacionais e lógicos para comparar números escolhidos pelo usuário.
- **jogo_de_adivinhacao**: Utilizo if, else e Math.random() para criar um jogo de adivinhação, no qual o programa sorteia aleatoriamente um número de 1 a 5 e verifica se o número escolhido pelo usuário corresponde ao número sorteado.
- **par_ou_impar**: Utilizo if e else para informar ao usuário se o número escolhido por ele é par ou ímpar.
- **teste_eleitoral**: O programa solicita a idade do usuário e, com base nela, utiliza estruturas condicionais (if e else) para determinar se o voto é obrigatório, facultativo ou proibido.
- **equacao_de_segundograu**: O programa resolve uma equação do segundo grau, calcula o valor do discriminante (delta) e apresenta suas raízes reais, utilizando a fórmula de Bhaskara.

## Como rodar

### Pré-requisitos

- JDK 17 ou superior instalado.
- VS Code com o *Extension Pack for Java* (opcional, porém bom).

### 1. Baixe o repositório

```bash
git clone https://github.com/MthNuness/java_learning.git
cd java_learning
```

### 2. Execute um exercício

**Pelo VS Code**

1. Abra a pasta `java_learning` em *Arquivo → Abrir Pasta*.
2. Dentro do exercício desejado, abra o arquivo `.java` que está em `src`.
3. Clique em **Run** (acima do método `main`) ou pressione `Ctrl + F5`.
4. Quando o programa pedir dados, digite-os no terminal integrado.

**Pelo terminal**

Entre na pasta do exercício e execute o arquivo (compila e roda em um passo só):

```bash
cd Hello_World
java src/HelloWorld.java
```
